# Этапы реализации

## 1. Каркас — текущий этап

- React + Next.js: мобильная страница сотрудника / и HR-экран /hr с проверкой API/БД.
- Пробное задание с объяснениями, результатом и сохранением прогресса в браузере.
- FastAPI, конфигурация, PostgreSQL/SQLAlchemy, Alembic без бизнес-таблиц.
- Доменные модели, расчёт навыков, раздельные порты scoring и объяснений.
- Роли employee/hr, Pytest, Docker Compose, lock-файлы и инструкции.
- Автономный AI-слой: gaps/readiness, отбор и scoring, OpenAI-план объяснения,
  шаблоны RU/KK/EN, демо на датасете и тесты. См. [интеграцию AI](ai-integration.md).

## 2. Данные и demo-доступ

ТЗ и датасет добавлены; read-only адаптер для AI готов. Для backend требуется
зафиксировать соответствие полей БД, шкалу навыков и грейды.
Добавить SQLAlchemy-модели и миграции, валидируемый импорт и demo-данные.
Реализовать JWT и серверное разграничение employee/hr.

## 3. Сквозной сценарий сотрудника

Профиль → разрывы до следующего грейда → 1–3 шага → завершение активности → новый прогресс.
Подключить реализованный deterministic scoring к данным backend и HTTP API.
Завершение активности сделать транзакционным и идемпотентным.

## 4. Объяснения и HR

Подключить готовый OpenAI-адаптер RU/KZ/EN с проверкой ответа и fallback, проверить живой вызов с ключом.
HR-срез по сотрудникам и навыкам с проверкой доступа. Интеграционные проверки сценариев.

## 5. Размещение demo

Выбрать Render/Railway/VPS по фактической доступности. Настроить HTTPS, секреты,
миграции, проверку readiness и smoke-тест с телефона. Публикация не входит в каркас.
