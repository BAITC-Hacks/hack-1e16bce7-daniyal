# Проверка frontend Career Quest

Дата проверки: 23 сентября 2026. Дата синтетического сценария: 1 октября 2026.
Этот документ описывает текущие `/` и `/hr`; `verification.md` хранит историю
проверок каркаса и не является отчётом о текущем интерфейсе.

## Соответствие Career Quest

| Пункт задания | Реализация / граница |
| --- | --- |
| Профиль и траектория | Текущая роль/грейд, заданная цель или следующий грейд, карта разрывов |
| 1–3 шага с обоснованием | Многофакторный локальный скоринг и раскрываемое объяснение; LLM пока нет |
| Новые профили и история жюри | JSON/CSV в схеме стартового набора; объединение по ID, проверка ссылок и значений до применения |
| Обновление после выполнения | Явное демо-завершение в плане, единый пересчёт сотрудника и HR |
| Правила роста | `gain` / `max_level`, максимум 5, без повторного начисления одной записи |
| HR-срез | Разрывы относительно карьерных целей, отделы, поиск, паузы от 60 дней |
| История отказов и пропусков | Отображается и влияет на рекомендации похожих мероприятий |
| Добровольность | Отмена добровольного участия; отсутствие участия само по себе не снижает уровень |
| Отсутствие публичного рейтинга | Нет лидерборда сотрудников; агрегаты — о потребности в развитии |
| Обязательные процессы | Видны в плане; исключены из рекомендаций и игровых наград |
| Мобильный интерфейс | Проверен в браузере при ширине 390 px; HR и сотрудник адаптивны |
| Запуск одной командой | После `npm ci`: `npm --prefix apps/web run dev -- --port 3100`; общий стек — Compose |
| AI-слой | Не реализован в текущей frontend-итерации; необходим отдельный этап |
| Права и приватность | Только публичное синтетическое демо; переключатель ролей не является авторизацией |
| Halyk SuperApp | Веб-прототип; SSO, WebView bridge и интеграция SuperApp не подключены |

## Результат финального прогона

Node.js 24.11.1: 7/7 модельных тестов, TypeScript и production-сборка пройдены.
Маршруты /, /hr и /hr/insights успешно собраны. git diff --check пройден.
Next.js сообщает лишь об игнорировании package-lock.json вне репозитория.

## Автоматические проверки

```sh
npm --prefix apps/web test
npm --prefix apps/web run typecheck
npm --prefix apps/web run build
```

Модельные тесты проверяют исходные 200 профилей, воспроизведение навыков после даты
оценки, завершение ровно один раз, отмену без начисления, ограничения прироста,
импорт дополнительных профилей, отклонение повреждённых данных и приоритет
критичного карьерного навыка перед минимальным нерелевантным навыком.

## Проверенные браузерные сценарии

- E0002: System Design Fundamentals → добавить → подтвердить демо-завершение.
  System Design и API Design: 1 → 2; покрытие цели: 62% → 66%.
  Изменение сохраняется после перехода и отражается в поиске HR.
- Поиск HR по точному ID и пустой результат, показ корректных состояний.
- Импорт `employees.json`: проверка, предпросмотр, применение; история демо сохранена.
- Экспорт JSON: скачанный файл прочитан с диска — 200 сотрудников, 40 мероприятий,
  60 навыков, 2 744 записи после тестового завершения.
- Сброс защищён диалогом; Escape закрывает его без изменения данных. После Escape и кнопки закрытия фокус возвращается на инициатор; после удаления карточки/строки — на текущую вкладку навигации.
- Более старая резервная копия явно включает режим полного восстановления, блокирует
  выбор объединения, предупреждает о замене и показывает 2745 → 2744 записи.
  Данные меняются только по действию «Восстановить из этой копии».
- Скриншоты сотрудника и HR при ширине 1440 и 390 px; в мобильном виде страница
  не имеет общего горизонтального переполнения, навигация прокручивается отдельно.
- В проверенных сценариях браузерная консоль не содержала ошибок/предупреждений.

## Границы проверки

Встроенный браузер не отдал событие download, поэтому результат экспорта подтверждён
файлом в Downloads. Физический телефон, screen reader, работа в Halyk SuperApp,
одновременные конфликтующие правки в двух вкладках и интеграции backend/Telegram
не проверялись. Формальные SLA 2/10 секунд не измерены нагрузочным тестом.
Impeccable detector недоступен: локальный движок не установлен и его кэш недоступен
для записи. Визуальная проверка выполнена по браузеру и сохранённым скриншотам.

LocalStorage подходит только для демонстрации. Для реального внутреннего контура
нужны авторизация и серверные права, подтверждённые результаты обучения, общая БД,
AI-сервис с оценкой качества рекомендаций и интеграция уведомлений.
